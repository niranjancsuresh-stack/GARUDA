What the lab expects from your CubeSat 🤝

The lab sends one-line commands over the same USB cable, such as CMD WHEEL_START 30 and CMD WHEEL_STOP. Please answer with one JSON line like {"ack":"WHEEL_START","ok":true}. Lines starting with # show up as friendly notes. If your firmware doesn't answer, the wheel test skips itself and tells you why.

Send these sensor keys in JSON or CSV (short or long names both work): temp, hum, ax, ay, az, gx, gy, gz, mx, my, mz, hdg, alt, lat, lon, batt, wheel, rssi.
